# ICFog.fr

ICFog.fr est un site dédié à la présentation des services d’un artisan spécialisé dans la **maintenance informatique** et les **réseaux**. Ce site a été développé à l’aide de [Next.js](https://nextjs.org) pour garantir performance, fiabilité et flexibilité.

## À propos

ICFog.fr propose des services professionnels de maintenance informatique pour les particuliers et les petites entreprises. Les activités incluent :

- Réparation et entretien de systèmes informatiques.
- Installation et optimisation de réseaux.
- Assistance technique et dépannage.

L'objectif principal d'ICFog est de fournir des prestations rapides et de qualité pour assurer le bon fonctionnement de vos outils technologiques.

## Fonctionnalités principales du site

Le site est équipé des fonctionnalités suivantes :

- **Page d’accueil moderne et informative** : mettant en avant les services et avantages proposés.
- **Contact simplifié** : grâce à un formulaire dédié pour les clients.
- **Présentation des services** : détaillant les prestations et solutions adaptées aux besoins.
- **Accessibilité et performance** : optimisées grâce à l’utilisation de Next.js et TailwindCSS.

## Prérequis au développement

Pour exécuter ce projet, vous aurez besoin de :
- Node.js (v16 ou supérieur recommandé)
- npm (ou un gestionnaire de paquets compatible)
- Clonage du projet via le dépôt local ou distant.

## Installation et démarrage

Pour démarrer le projet localement, suivez ces étapes :

1. Clonez le dépôt :
   ```bash
   git clone <URL_DU_DEPOT>
   ```

2. Accédez au dossier téléchargé :
   ```bash
   cd icfog
   ```

3. Installez les dépendances :
   ```bash
   npm install
   ```

4. Lancez l’environnement de développement :
   ```bash
   npm run dev
   ```

5. Rendez-vous sur [http://localhost:3000](http://localhost:3000) pour visualiser le site en développement.

## Déploiement

Ce projet peut facilement être déployé sur [Vercel](https://vercel.com).

1. Connectez votre dépôt à Vercel.
2. Suivez le processus d'intégration pour un déploiement automatisé.
3. Une fois déployé, votre site sera accessible via une URL publique.

## Technologie utilisée

ICFog.fr repose sur :
- **Next.js 15.3.3** : pour un rendu dynamique et efficace.
- **React 19.0.0** : pour une interface utilisateur réactive.
- **TailwindCSS** : pour un design adaptatif et élégant.
- **TypeScript** : pour une expérience de développement robuste et typée.
